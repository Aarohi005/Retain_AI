
# 🏦 ChurnIQ: Customer Churn Intelligence Platform

An end-to-end machine learning system for predicting customer churn and analyzing behavioral risk patterns in banking data.

This project combines **XGBoost (supervised learning)** for churn prediction and **K-Means clustering (unsupervised learning)** for customer segmentation, deployed through an **interactive Streamlit dashboard** for real-time insights and decision-making.

---

## 🚀 Key Features

- 🔍 Churn prediction using **XGBoost (82% accuracy, 73% recall)**
- 🧩 Customer segmentation using **K-Means clustering**
- 📊 Interactive dashboard with **dynamic filters (age, geography, activity)**
- 📈 Model evaluation using **confusion matrix & precision-recall metrics**
- 🎯 Real-time **churn risk prediction tool**
- 💡 Actionable insights for **customer retention strategies**

---

## 🧠 Problem Statement

Customer churn is a major challenge in banking, leading to:
- Reduced customer lifetime value
- Increased acquisition costs
- Revenue instability

This project aims to:
- Identify high-risk customers
- Analyze churn patterns across demographics and regions
- Provide actionable insights for retention strategies

## 📊 Model Performance

| Metric        | Value |
|--------------|------|
| Accuracy     | 82%  |
| Recall (Churn) | 73% |
| Precision (Churn) | 54% |
| Weighted F1-score | 0.83 |

### 🔍 Key Insight:
The model is optimized for **recall**, ensuring most churn customers are detected, even at the cost of lower precision.
